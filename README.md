# 👗 ModaX – Multi Vendor Fashion Store (💡 University Project – Full Stack Web Application)

A modern multi-vendor fashion e-commerce platform built as a university project using PHP, JavaScript, AJAX, and Bootstrap. ModaX provides a smooth and interactive shopping experience with real-time updates, live search, and a powerful admin dashboard for managing products and users.

🚀 Overview

ModaX is a full-stack fashion marketplace where multiple vendors can sell their products in one platform. It is designed to simulate a real-world online clothing store with dynamic features such as live product loading, AJAX-based interactions, and an admin analytics system.

The system focuses on speed, smooth UX, and real-time interactivity.
